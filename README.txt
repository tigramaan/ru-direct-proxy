RU-DIRECT-PROXY — РАЗДЕЛЕНИЕ САЙТОВ ДЛЯ WINDOWS

Чтобы не приходилось постоянно включать и выключать VPN: российские IPv4
идут напрямую, остальные — через VPN, когда он подключён.
Проект и новые версии: https://github.com/tigramaan/ru-direct-proxy

Для Windows 10/11 x64. Python и права администратора не нужны.
Комплект работает с уже установленным VPN, включая hidemy.name.
Он не устанавливает VPN и не переносит подписку или почтовые учётные записи.

УСТАНОВКА НА ДРУГОМ КОМПЬЮТЕРЕ

1. Распакуйте ZIP целиком в обычную папку. Не запускайте BAT прямо внутри ZIP.
2. Подключите Wi-Fi или Ethernet. Закройте Thunderbird, если он открыт.
3. Запустите INSTALL.bat обычным двойным щелчком.
4. Подключите VPN в его приложении как обычно. Откройте браузер и Thunderbird.

Программа сама определяет физический сетевой адаптер и его IPv4-адрес.
При смене адреса или переключении Wi-Fi/Ethernet она пересоздаёт локальный
прокси. Если работают оба подключения, используется интерфейс с меньшей
метрикой маршрута по умолчанию.

ФАЙЛЫ УПРАВЛЕНИЯ

INSTALL.bat — первая установка и включение.
ENABLE.bat — повторное включение после отключения.
DISABLE.bat — восстановление прежних настроек прокси и отключение автозапуска.
CHECK.bat — состояние программы и выбранный сетевой адаптер.

Для обновления комплекта сначала запустите DISABLE.bat, затем INSTALL.bat
из новой распакованной версии. После переключения перезапустите Thunderbird.

КАК РАБОТАЕТ

Российские IPv4-адреса из базы GeoIP открываются через физическое подключение.
Остальные используют обычное подключение Windows: через VPN, когда он включён,
и напрямую, когда выключен. Определение страны зависит от базы GeoIP; домен
«.ru» сам по себе не означает, что сервер находится в России.

Chrome и Edge используют системную автоматическую настройку прокси.
Для зарегистрированных профилей Thunderbird включаются системные настройки
прокси. В Firefox и других браузерах при необходимости выберите «Использовать
системные настройки прокси», если раньше был настроен собственный прокси.

Это схема для приложений, которые учитывают системный прокси. Она не разделяет
весь трафик всех программ. DNS внутри прокси использует HTTPS к 1.1.1.1 через
физическое подключение. Обычные запросы разрешаются в IPv4; IPv6 не проверен.
VPN должен разрешать прямые подключения: блокирующий их Kill Switch может
помешать открытию российских адресов напрямую.

Системные маршруты, настройки Wi-Fi, DNS адаптеров и шаблоны VPN программа
не меняет. Если локальный прокси недоступен, браузер может вернуться к обычной
маршрутизации Windows. HTTPS и почтовый TLS остаются между приложением и сервером.

ГДЕ ХРАНЯТСЯ ФАЙЛЫ

Программа копируется в %LOCALAPPDATA%\BrowserCountryProxy текущего пользователя
и запускается автоматически при его следующем входе в Windows.
В settings-before.json сохраняются прежние настройки этого компьютера.
Этот файл создаётся при установке; его нельзя переносить с другого компьютера.
Исходный архив не содержит ваших паролей, учётных записей, журналов или резервных
копий. Для других пользователей Windows установку нужно выполнить отдельно.

Если нужен полный откат, запустите DISABLE.bat и перезапустите Thunderbird.
Файлы программы остаются в указанной папке для повторного включения.

КОМПОНЕНТЫ

Лаунчер CountryProxy.exe использует встроенный в Windows .NET Framework 4.x.
