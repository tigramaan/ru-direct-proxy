# ru-direct-proxy

**Оставьте VPN включённым: российские IP — напрямую, остальные — через VPN.**

VPN нужен для одних сайтов, но с ним могут перестать открываться российские
сервисы и почтовые серверы. Приходится постоянно включать и выключать VPN,
перезагружать страницы и ждать подключения.

`ru-direct-proxy` автоматически выбирает путь для браузеров и Thunderbird.
Российские IPv4-адреса из базы GeoIP используют ваше Wi-Fi или Ethernet,
а остальные — обычную маршрутизацию Windows, то есть подключённый VPN.
Когда VPN выключен, остальные адреса тоже открываются напрямую.

## Скачать и установить

**[Скачать готовый ZIP для Windows 10/11 x64](https://github.com/tigramaan/ru-direct-proxy/releases/latest)**

1. Скачайте `ru-direct-proxy-*-windows-x64.zip` со страницы Releases.
2. Распакуйте архив целиком в обычную папку.
3. Подключите Wi-Fi или Ethernet. Закройте Thunderbird, если он открыт.
4. Запустите `INSTALL.bat` двойным щелчком.
5. Подключите VPN как обычно. Откройте браузер и Thunderbird.

Python и права администратора для установки не нужны. VPN должен быть уже
установлен и настроен. Программа сама выбирает физический сетевой адаптер
и его IPv4-адрес; при смене сети обновляет локальный прокси.

| Файл | Назначение |
| --- | --- |
| `INSTALL.bat` | Первая установка и включение |
| `ENABLE.bat` | Включение после отключения |
| `DISABLE.bat` | Отключение и восстановление прежних настроек прокси |
| `CHECK.bat` | Проверка состояния и выбранной сети |

Для обновления сначала запустите `DISABLE.bat`, затем `INSTALL.bat` из новой
версии. После включения или отключения перезапустите Thunderbird.

## Как это работает

Браузер или Thunderbird отправляет соединение локальному прокси. Прокси
определяет IP сервера и проверяет его по российской базе GeoIP.

| Адрес назначения | Путь |
| --- | --- |
| Российский IPv4 | Через физическое Wi-Fi или Ethernet |
| Остальной IPv4 | Через активный VPN, если он подключён |
| Локальная сеть | Через физическое подключение |
| `localhost` | Напрямую внутри компьютера |

В основе — официальный [sing-box](https://github.com/SagerNet/sing-box)
и [база SagerNet/sing-geoip](https://github.com/SagerNet/sing-geoip).
Собственный EXE запускает прокси, обслуживает PAC-файл, применяет настройки
текущего пользователя Windows и сохраняет их для отключения.

Программа не меняет системные маршруты, DNS адаптеров, настройки Wi-Fi
или конфигурацию VPN. TLS остаётся между браузером или почтовым клиентом
и сервером. Внутренний DNS прокси использует HTTPS к `1.1.1.1` через физическую сеть.

## Совместимость и ограничения

- **Windows 10/11 x64**, подключение по Wi-Fi или Ethernet.
- Программа не привязана к hidemy.name. Проверена с **hidemy.name / OpenVPN**;
  совместимость с другими VPN-клиентами требует проверки.
- VPN должен разрешать прямые соединения. Kill Switch, запрещающий обход VPN,
  может блокировать российские адреса и внутренний DNS прокси.
- Chrome и Edge обычно используют системную настройку прокси. В Firefox
  и других браузерах выберите «Использовать системные настройки прокси».
- Для зарегистрированных профилей Thunderbird включается системный прокси.
  Почтовые аккаунты и пароли не изменяются и не переносятся между компьютерами.
- Разделение действует для приложений, учитывающих системный прокси;
  оно не распространяется автоматически на все программы и протоколы.
- Страна определяется по IP, а не по домену. Сайт в зоне `.ru` может находиться
  на зарубежном сервере, а сайт в другой зоне — на российском.
- Обычные доменные запросы внутри прокси разрешаются в IPv4. Отдельные
  сценарии IPv6 не проверены. База GeoIP включена в ZIP и автоматически не обновляется.
- В PAC предусмотрен возврат к обычному подключению Windows, если локальный
  прокси недоступен. Это утилита выбора маршрута, а не средство принудительной изоляции трафика.

## Если сайт не открывается

Запустите `CHECK.bat`: разделение должно быть включено, а физическая сеть —
определена. Проверьте подключение VPN и настройки системного прокси в браузере.
После установки перезапустите Thunderbird.

Если VPN запрещает прямые соединения, российский сайт может не открыться
даже при верной базе GeoIP. Если IP сайта классифицирован неверно,
путь может отличаться от ожидаемого. Для проверки обычного подключения
запустите `DISABLE.bat` и перезапустите Thunderbird.

Сообщить о проблеме можно в [Issues](https://github.com/tigramaan/ru-direct-proxy/issues).
Укажите версию Windows, VPN-клиент, браузер и адрес сайта. Не прикладывайте
пароли, почтовые профили или `settings-before.json`.

## Где находятся файлы

Установка выполняется отдельно для каждого пользователя Windows:

```text
%LOCALAPPDATA%\BrowserCountryProxy
```

В этой папке хранятся EXE, прокси, база IP, локальная конфигурация, журналы
и резервная копия прежних настроек `settings-before.json`. Программа
добавляется в автозагрузку текущего пользователя при входе в Windows.

`DISABLE.bat` останавливает прокси, восстанавливает сохранённые настройки
и прежнее значение автозагрузки, а также удаляет своё изменение настроек
Thunderbird. Файлы установки остаются для повторного включения.

Исходный ZIP не содержит паролей, VPN-профилей, почтовых аккаунтов,
журналов или резервных копий с компьютера разработчика.
