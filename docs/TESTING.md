# Проверка комплекта

Для первой версии на Windows 11 x64 с Wi-Fi и hidemy.name / OpenVPN проверены:

- автоматическое обнаружение физического адаптера при подключённом VPN;
- TLS-соединение через локальный SOCKS с GitHub, IMAP и SMTP Beget;
- доступность российского сайта `rit-robotics.tech` через прямое подключение;
- применение PAC в Windows и открытие сайта в Chrome;
- выдача PAC-файла локальным сервером;
- включение и отключение с точным восстановлением сохранённых значений
  системного прокси и пользовательской автозагрузки;
- сохранение системных маршрутов при работе прокси;
- запуск из пути с пробелами и кириллицей;
- отсутствие пользовательских профилей, паролей, журналов и резервных копий
  в архиве.

Другие VPN-клиенты, Windows 10, смена физической сети и отдельные сценарии IPv6
не проходили полноценную проверку. Переподключение VPN и запуск после входа
в Windows также требуют отдельной проверки; наличие соответствующего кода
не заменяет такую проверку.

## Автоматическая проверка после сборки

```powershell
.\build-package.ps1
.\test-package.ps1
```

Сценарий создаёт отдельную рабочую папку, запускает тестовый прокси,
проверяет конфигурацию sing-box и TLS к трём публичным серверам,
затем останавливает тестовый процесс. Для этих сетевых проверок нужен интернет.
Сценарий не включает глобальный прокси Windows и не изменяет настройки Thunderbird.

В JSON-отчёте должны быть `true` у полей:

```text
github_tls
beget_imap_tls
beget_smtp_tls
routes_unchanged
windows_proxy_unchanged
```

Отчёт создаётся внутри `work/`. Он содержит название локального адаптера
и его IP, поэтому не публикуйте его без удаления этих данных.

## Проверка на другом компьютере

1. Сохраните текущие настройки прокси и закройте Thunderbird.
2. Распакуйте ZIP и запустите `INSTALL.bat`, затем `CHECK.bat`.
3. С подключённым VPN проверьте российский сайт, зарубежный сайт и почту.
4. Переподключите VPN и повторите проверку.
5. Проверьте запуск после нового входа в Windows.
6. Запустите `DISABLE.bat`, перезапустите Thunderbird и проверьте восстановление
   прежних настроек.
